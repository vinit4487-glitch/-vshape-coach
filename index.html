Coach’s rules

• Most exercises: 2 challenging working sets.

• Main lifts: rest 2–3 minutes; isolation: 60–90 seconds.

• Stop most sets with 1–3 clean reps in reserve (RIR). Failure is not required.

• Add reps first. Add load only after both sets reach the top of the range at target RIR.

• Do not add sets automatically. Track performance, waist, body weight and recovery.

Install on iPhone

  1. Host the included files on an HTTPS site (for example, GitHub Pages).
  2. Open the hosted site in Safari.
  3. Tap Share → Add to Home Screen.
  4. Open V-Shape Coach from your Home Screen.

The app can work offline after its first successful load when hosted over HTTPS. Keep backups: browser storage can be cleared by iOS or by deleting website data.

Reset all app data
