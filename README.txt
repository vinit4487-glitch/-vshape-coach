V-SHAPE COACH v3 — iPhone PWA

FILES
- index.html: tracker app
- manifest.webmanifest: installable app metadata
- sw.js: offline caching after first successful load over HTTPS
- icons/: app icons

FEATURES
- Dashboard and 12-week phase navigation
- Six-day revised split with exercises, sets, reps, RIR
- Two working sets per exercise, with load/reps/RIR entry
- Completion tracking and workout notes
- Body weight and waist log with trend charts
- PR board based on completed exercise logs
- Daily habits, protein, steps, sleep, optional calories and notes
- JSON backup export/import
- Local browser storage

INSTALL ON IPHONE
1. Host the contents of this folder on an HTTPS static host (e.g. GitHub Pages).
2. Open the hosted index.html in Safari.
3. Tap Share -> Add to Home Screen.
4. Launch V-Shape Coach from the Home Screen.

IMPORTANT
- Data is stored locally in the browser on this device. Export JSON backups regularly.
- Clearing website data or deleting the app may remove local data.
- Offline caching works after first successful load over HTTPS.
